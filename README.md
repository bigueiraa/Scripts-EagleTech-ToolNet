# Scripts-EagleTech-ToolNet
Arquivo .bat para testes de conexão.

*COMO USAR*

Baixe o arquivo
Execute o arquivo EagleTech_ToolNet.bat como Administrador
Vai abrir uma tela no CMD com os comandos de teste de conexão.

*Para um troubleshooting eficiente, vá além do ping:
Tracer / traceroute - Mostra o caminho que o pacote faz até o destino.
Telnet - Testa conectividade em portas específicas de um serviço.
Nslookup - Verifica resolução de nomes (DNS).
Netstat - Mostra conexões ativas e portas em uso.
Patt-netconnection - Valida conectividade com host e porta (Windowns)

Dica: Entender o que testar e interpretar o resultado é o que realmente resolve o problema.
